# План — ОС, программы и драйверы

Открытое по ОС, программам (`soft/`) и драйверам (пакеты `saltic-registry`). Перенесено
из плана языка `saltic/docs/plan/PLAN.md` 28.11.2026 (решение автора: план языка — только
язык). ОС не перестраивается без нового решения автора (`saltic/docs/os/OS-core.md`).
Подробности каждого пункта (аудиты 02–03.11, Wi-Fi, видеокарты) — в архиве языка
`saltic/.archive/docs/plan/PLAN-3.md`. Видение и хотелки — автора; сделанное — вычёркивать
из списка сразу.

- [ ] Обёртки `firmware.number(…)` — убрать, адрес уже число.
- [ ] Коды прошивки, сканкоды и сеть — каждое в одном месте; `files.write_file` /
  `files.delete` вместо трёх копий; мелкие повторы; утечки страниц и пула на
  путях ошибок.
- [ ] Три стека на одно (точка, текст, клавиша, мышь, время) → один (решение автора 28.11).
- [ ] UIEngine: частичная перерисовка (цель — 50 мс), лента сообщений и живое
  поле ввода, свой буфер пикселей, диспетчер компонентов и токены отступов.
- [ ] **решение** InterEngine — устройство: отдельным разговором с автором.
- [ ] Редактор кода в ОС.
- [ ] Wi-Fi: WPA2; проверка живости связи (пропадает молча).
- [ ] NVIDIA GTX 950M: видеопамять (**отложено** — нужен devinit), копировальный
  движок, графический движок.
- [ ] Видеокарта Intel: прозрачность — 3D виснет на первом кадре стекла.
- [ ] Программа — карточка с двумя сторонами: лицо и оборот с логом,
  ошибками, состоянием, кадрами, памятью — в SalticIDE (решение автора 28.11).
